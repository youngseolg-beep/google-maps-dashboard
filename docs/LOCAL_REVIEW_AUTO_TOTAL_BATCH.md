# Automatic total count pilot
Count-only batch --auto-total uses direct verified place URLs with English UI.
The Overview rating summary must yield the same unambiguous positive bounded
integer twice. If the review tab is already selected, first verify Overview
navigation. Zero, ambiguous, changing, missing or above-limit totals are held,
not guessed. Other eligible stores continue, access restrictions stop batch.
Automatic total is opt-in, mutually exclusive with manually supplied targets
and DB-audit modes. Counts are observations, not full-text/coverage proof.
Existing explicit count behavior retained. No new writes, scheduler, or schema.

then a single Thailand automatic count pilot before broad registered scans.
